# CLAUDE.md

## Punctuation rules

- All comments, text, and commit messages must use **English punctuation only** (`.`, `,`, `:`, `;`, `!`, `?`, `()`, `[]`, etc.).
- Do NOT use Chinese punctuation marks like `。`, `，`, `：`, `；`, `！`, `？`, `（）`, `【】`.
- Chinese text content itself is not affected -- only punctuation marks must be in English.

## Period rules

- Comments must NOT end with a period `.`.
- Commit messages MUST end with a period `.`.
